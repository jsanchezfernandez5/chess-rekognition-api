Dataset YOLO26 — Anotación semi-automática

Pre-rellena cajas desde las predicciones de TensorFlow sobre el tablero rectificado 400x400. Revisa, corrige, borra o añade cajas y guarda.

1 · Capturar / subir imagen del tablero

Flujo interno: /vision/recognize-board (homografía → tablero rectificado limpio 400x400) y después /vision/classify con las mismas esquinas, para pre-rellenar las cajas. Para la clase "hand", haz fotos a propósito con la mano/dedo moviendo una pieza y añade la caja manualmente.

2 · Revisar y corregir cajas

Arrastra dentro de una caja para moverla; usa los tiradores de las esquinas para redimensionarla (el superior-izquierdo permite extenderla hacia la fila anterior, donde la pieza sobresale por la perspectiva). Toda caja pre-rellena que se mueva/redimensione/recalifique pasa a contarse como "corregida". Tecla Supr para borrar la seleccionada.
